# Hospital Management System

A backend REST API for a Hospital Management System built using Spring Boot. This project is being developed to learn and implement real-world backend development concepts such as authentication, database management, security, and RESTful API design.

## Features

- RESTful CRUD APIs
- DTO Pattern
- Input Validation
- Global Exception Handling
- Pagination
- Sorting
- Searching
- JPQL Queries
- Native SQL Queries
- Entity Relationships
- Spring Security
- JWT Authentication
- OAuth2 Login (Google & GitHub)


## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- JWT
- OAuth2
- PostgreSQL
- Maven
- Hibernate
- Lombok
- ModelMapper
- Bean Validation
- Postman
- Git & GitHub



## API Features

- Authentication using JWT
- Login with Google and GitHub
- CRUD operations
- Request validation
- Exception handling
- Pagination & Sorting
- Search APIs
- JPQL & Native Queries
- Entity Relationships
